# prioritySV
Merge SurVeyor, hitSV/gcSV and Manta VCFs based on their matching accuracy in specific SV size bins from benchmarking data.

## Installation
Requires Truvari v5.3.0, bcftools (only tested v1.15.1), and bedtools (only tested v2.29.0) to be available in your PATH.
Note: Other bcftools and bedtools versions should work, but carefully check output for what is expected

ANNOVAR must also be installed and available in your PATH if using the ANNOVAR annotation option.

Navigate to the releases page ( and download the .tar.gz archive.
